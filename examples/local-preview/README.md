# Local fictional preview

Open `dashboard.html` directly in a browser. No server, package, model API, database or network connection is used. Choose `sample.csv` to try a valid file, `invalid.csv` for a malformed value, or `empty.csv` for an empty-input error.

The page supports only `Total orders` and `Total revenue`; other questions receive an explicit unsupported response. This example is a deterministic local preview, not an AI chatbot. The measured test results and untested limits are in the repository's `TEST-REPORT.md`.
